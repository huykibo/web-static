# IRONFIT — Premium Activewear Static Store

A polished, responsive static e-commerce front-end for GitHub Pages.

## Pages
- Home
- Shop
- Men
- Women
- New Arrivals
- Sale
- Product detail
- Cart
- About
- Contact / FAQ

## Features
- Premium editorial activewear layout
- Responsive desktop/tablet/mobile UI
- Product filtering and sorting
- Search drawer
- LocalStorage shopping bag
- Quantity controls
- Newsletter/contact demo interactions
- GitHub Pages ready

## Deploy
Upload the entire folder to a GitHub repository with `index.html` at the root.
Enable GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Note
This is a front-end demo. Checkout, payment, email delivery and inventory are not connected to a backend.
Product photography uses remote Unsplash image URLs.
