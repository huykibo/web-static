# IRONFIT — Premium Fitness E-commerce

Responsive static e-commerce storefront built with HTML, CSS and vanilla JavaScript.

## Included
Home, Shop, Men's Collection, Women's Collection, New Arrivals, Sale, Product Detail, About, Contact and Shopping Cart.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## GitHub Pages
Create a GitHub repository, upload all files, then go to **Settings → Pages → Deploy from a branch → main → / (root)** and Save.

## Notes
- Product/cart/wishlist interactions are demo front-end functionality using browser localStorage.
- Contact/newsletter forms are demo UI and need a real backend/email service for production.
- Demo photography uses remote Unsplash image URLs. Replace them with licensed/local assets for a production client site.
